# Canonical SHA-256 Git pack fixtures

These two complete pack/index pairs were produced with the AOS source-built
Git 2.55.0. `manifest.json` retains exact encoded SHA-256 commitments, path
trailer identities, object identities and `git verify-pack -v` observations.
Both contain commit, tree, tag and blob objects; the changed blob is a delta.

The source repository used `git init --bare --object-format=sha256`. Blob
contents are the `base_content` and registry strings in `projection_tests.rs`.
`git hash-object -w --stdin`, `git mktree`, `git commit-tree` and `git mktag`
created the objects. The commit and tag use `Fixture Author
<author@example.test>` and timestamp `1700000000 +0000`.

The six selected object IDs were supplied to:

```text
git pack-objects --stdout --window=10 --depth=10 --delta-base-offset
git pack-objects --stdout --window=10 --depth=10
git index-pack --index-version=2 -o <mode>.idx <mode>.pack
git verify-pack -v <mode>.idx
```

The first pair contains an offset delta; the second a reference delta. Tests
consume these retained Git-generated bytes without requiring a host Git or
skipping an interoperability gate. Fixture success establishes parser behavior,
not a deployed provider or mirror qualification.
