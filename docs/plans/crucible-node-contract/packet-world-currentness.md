# Packet world currentness and collection

The fixed output-only packet profile admits three original peers into one world.
Its nine windows issue 27 grants and check each result before and after the
original publication acknowledgement. The resulting 54 checks retain 27 durable
result roots and one activation. This profile refuses incoming input; connected
packet semantics require a separate source-owned input journal and commitment.

Original artifact validation retains each read-only descriptor and checks its
path, inode, extent, revision and process. Issuance hashes the complete retained
descriptor. A kernel read lease, acquired once before measurement, allows later
checks to retain that full-byte result. Notification targets an owned thread
that blocks SIGIO only in its own mask. Checks before and after source callbacks
read the actual kernel lease. A pending break permanently refuses the original
source, including after bytes are restored or the kernel break timeout expires.
Initial unsupported or conflicting acquisition permanently selects full-byte
validation. A successfully acquired lease never falls back or renews.

Exact artifact-tuple deduplication shares an original currentness owner within
the admitted roster. It does not reuse authority across time. Idle Unix-socket
readiness starts the next complete-frame deadline without renewing that deadline
for partial reads. The original authenticated stream remains the parser owner.

The matched workload uses the same final guard, peer executable, compiler
profile, full-byte fallback and source/path/process fences. Its only baseline
change disables initial lease acquisition.
