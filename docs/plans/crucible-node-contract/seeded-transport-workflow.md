# Seeded transport workflow

The installed seeded link provides a normal deterministic source→link→Block
scenario. It applies the existing integer `NetLink` jitter and reorder model to
original Block request octets. It does not decode frames as Ethernet or invent
storage responses. The Block node continues to decode and execute its authentic
ordinary input lane.

An operator independently enrolls a canonical `SeededLinkDefinition` artifact.
The portable selection names its `ContentRef`, scripted producer and Block
consumer. The model, configuration, initial state, implementation identity and
`host/native-seeded-link-v1` format bind that definition. The generic exact
execution facet retains its ordinary timing contract; its selected configuration
and guarantees are regenerated from the actual installed seeded implementation.
The existing fault-free HostNetLink profile, model and native bytes stay intact.

The selected edition admits at most sixteen immutable source requests, static
jitter and reorder windows, and a positive picosecond latency floor. Other fault
parameters and dynamic fault controllers are not part of this definition. A
9p sink is refused by this edition rather than inheriting Block qualification.
The source, link and consumer have distinct native owners. The link owner owns
the complete native fault table, clock, frame sequence, seeded stream cursor and
pending frame queue. Each coordinator transfer has a separate authoritative FIFO
and credit domain owned by its actual receiving endpoint, with both endpoints
listed as writers.

The link resumes the existing per-device decision stream at its captured cursor
for every newly consumed original input. It consumes the existing five draws
per frame, including the unused never-firing loss/duplicate/corruption selectors.
The signed native codec retains both the exact seed/name definition and complete
existing LinkSnapshot. Restore rejects a different program, stream, fault table,
timing or RNG cursor. It never redraws a retained frame. Input staging, original
native outcomes, publication receipts, acknowledgements, causal parents and
coordinator payloads use the same complete original-custody runtime as storage.
A pending link-produced FIFO is authenticated against the original complete
native publication ledger and independently regenerated installed topology.

Cold restore still requires independently pinned operator artifact identities.
ArchiveOnly enrollment permits the signed complete original bytes to construct
scoped private inputs after the original files disappear. It cannot enroll a
new backend, accept an absent closure, rewrite the source scenario, or authorize
fresh native construction. The optional deterministic result-reuse path also
regenerates the selected seeded profile; all existing whole-world roster and
immutable original-result closure gates remain mandatory.

The implementation tests run the ordinary ObservedAttemptWorker and the genuine
installed signed HostArchive path. A source captures a pending native frame at
RNG cursor five, then a later cut with the actual link→disk coordinator FIFO.
An uninterrupted source continues as an independent output and state oracle.
After deleting all original artifact paths, registry and native worlds, two fresh
branches resume each capture. They reproduce original payloads, positions,
causal membership, correlations and sequences, reach RNG cursor ten with the
same complete native state, and produce each write/read once. Changed program
bindings refuse before native reservation; parser tests separately reject altered
seed/name/fault/cursor state and excessive content. These checks qualify this
bounded static transport workflow, not general signal-driven fault plans,
clock transforms, guest CPU/device fidelity or debug continuation.
