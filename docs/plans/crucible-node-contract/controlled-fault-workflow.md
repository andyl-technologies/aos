# Authored coefficient-controller workflow

The installed `host_controlled_fault_link` selection executes an immutable
controller program through the normal exact node executor. It connects an
installed finite scripted source to a Block device or an opaque packet receiver.
The operator enrolls canonical program bytes independently; remote selections
contain its complete `ContentRef` and endpoint names, never an artifact path,
qualification receipt, or a caller-created mutation permit.

The controller defines one to sixteen strictly increasing `(time_ps, 0,
BoundaryControl)` decisions. Each decision replaces only the rational loss,
duplication, and corruption coefficients. The initial seed, named RNG stream,
source identity, positive latency/floor, duplicate gap, and topology stay fixed.
The Block selection refuses corruption because changed bytes need not remain a
valid Block request. The packet receiver accepts bounded opaque bytes and echoes
the actual received bytes; it does not implement Ethernet or guest CPU behavior.

The exact planner parks at each decision before staging later inputs. It acquires
the actual `FaultInjection` facet and issues an original `FaultInjectionV1`
operation beneath the current world activation, owner/domain reservation, and
runtime token. The native model checks the selected profile, complete program,
actual cursor, consumed-input prefix, and original operation identity. It reserves
complete journal and receipt/table storage before changing coefficients. The
result advances no modeled time and produces no output. Only later consumed
inputs use the changed coefficients; previously resolved queued packets retain
their original bytes, coordinates, sequences, and draw history.

Each applied decision retains its original operation, owner roster, source
activation context, request, consumed-input prefix, and complete previous/applied
table references. Input decisions retain raw RNG draws and zero-, one-, or
two-output results, including zero-output loss. A preparatory cached result is
insufficient: original result queries authenticate the actual applied native
journal before returning completion. Reusing an operation identity cannot apply
another change. Recovery queries and acknowledges the original operation.

The source-qualified implementation is `crucible-host-controlled-fault-link`,
with role `controlled_fault_transport`, facet `host/fault-injection-v1` edition
one, and native format `host/native-controlled-fault-link-v1` edition one. Its
selected capture uses Host native envelope three, runtime snapshot four, and
coordinator record three. Scheduler snapshot three is selected only while a fault
permission remains reserved. Authenticated original-epoch snapshot two remains a separate grammar.
Legacy runtime/native capture paths refuse this
scope rather than omitting controller state. Legacy formats and fault-free link
bytes stay unchanged. The generic capability resolver does not infer installed
operation policy from these descriptors; explicit reviewed source-policy
enrollment is still required for its separately negotiated route.

The state executor chooses `capture_fault_world` for this implementation. A cold
restore authenticates the complete original scenario, backend/model/configuration,
controller program, runtime/scheduler ledger, native queues, and receipt/table
closure before allocation. It keeps historical original mutation contexts intact.
Saved Complete operations are queried, committed through the authentic scheduler
when necessary, and acknowledged before later grants; they are never begun again.
Later newly authored decisions use the fresh actual world authority. An
`ArchiveOnly` installation independently pins expected artifact identities while
the signed closure supplies bytes after original asset paths are removed.

The native regression scenarios independently check duplicated original writes,
a lost subsequent write, unchanged final Block read data, and opaque corruption
against a separately advanced seeded bit-selector oracle. The signed cold tests
capture an applied decision before coordinator commit/native ACK with queued
original packets, remove original worlds/catalog/assets, and continue two fresh
worlds. They compare original receipt/context, output bytes, full causal
coordinates/sequences, RNG position, native FIFO, and future decisions. A further
state-executor test captures after the first decision and continues two fresh
worlds after source asset removal. Early mutation preserves the exact runtime
snapshot; legacy extraction/capture and wrong controller bindings refuse.

This scope does not include scheduler-changing latency/topology mutations,
external live controller choices, mutation replay of changed contexts, debug
commands, or combined terminal-assertion/fault preservation. No guest CPU,
full-system device parity, or Linux performance claim follows from this workflow.
