# Typed role views

Role interfaces return fallible borrowed descriptions of the actual admitted
descriptor and complete profile content reference. The fields expose concrete
processor, storage, filesystem, link, clock, or external-device semantics.
Reading a description supplies no admission, grant, readiness, or mutation
authority; operations continue through the common node contract.

The host adapter exposes its realized block, read-only 9P, network-link, or
clock model. Its selected descriptor controls which role is present, and absent
roles refuse. Static source parameters are retained once at construction;
restoration does not replace them with mutable current values. Queues, fids,
negotiated message size, RNG progress, and clock frontiers may advance without
redefining the original model. The coordinate clock exposes no alarm service;
the rational alarm extension requires its separately enrolled profile. Host
compute is unsupported. The controlled external adapter checks original process
and thread custody before invoking child hooks and reports its actual limits on
pause and preservation.

models, plus definition drift and absent-role refusal. Six existing host
initialization, restoration, and clock controls pass from the same frozen
component executable. All-target strict Clippy passes on a separate current
source join containing the identical role changes and a narrow packet lint fix.

newly executed by these controls. These checks do not qualify an installed
backend or a complete multi-role vendor implementation. Raw evidence remains
