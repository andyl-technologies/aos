# Public input commitment journal

The reference provider negotiates `reference-device/input-commit/1` on the
existing CNP/1 `Input` envelope. Staging alone leaves native execution closed.
The later request binds the original accepted batch and receipt to the complete
canonical coordinator delivery inventory, world activation, owner incarnation,
and exclusive input cut. The source checks the actual retained payload bytes
before recording the commitment.

Both endpoints retain their original attempt before transport or receipt
effects. The source owns the immutable commitment request and a copy of the
actual input bytes. A failure after entering the effect path remains Unknown;
replaying the original request cannot create another attempt. A completed
source journal entry and the matching byte population are required before
`QuantumBegin`. Commitment evidence augments the standard `InputCustodyRecord`
through its evidence references. Consumed commitments remain in runtime history
and the private retirement export.

Verification uses the exact frozen 25-file successor. All targets of the three
selected crates compile. Three actual Unix-socket/provider/child controls pass:
an empty input cut, a nonempty cut with two events and 259 payload bytes, and an
unnegotiated peer. They also cover staging-only refusal, changed incarnation or
inventory, exact original-request replay, the child's executable and parent
ancestry, and native byte counts and checksums. Retained compiler dependency
files and independently copied child executables bind this evidence to the
tested source. Raw evidence stays local.

The native smoke/conformance callers now negotiate the commitment extension,
upload the complete inventory, and commit the original staged input before
execution. The lineage guard forwards these requests through its original
kernel/read-owner fences. The conformance runner allows only the closed Input
intent selected by the actual handshake and rejects echoed response extensions.
Five actual provider/client/lineage targets pass 325 controls; 14 tests remain
ignored. All targets of the three selected crates compile on the exact caller
successor. These results preserve their separate compiler/source scope.

The ordinary installed package, complete singleton conformance, and end-to-end
cleanup still need qualification. Generic vendor and lineage-reader consumption hooks
continue to refuse unsupported behavior. This stage does not qualify native
backend readiness or mixed-machine state preservation.
