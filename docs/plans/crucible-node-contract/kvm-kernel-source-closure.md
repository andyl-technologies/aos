# KVM constructor kernel source closure

The selected `linux-controller-q35-cold-kernel` variant applies the complete
fourteen-patch native chain to the pinned ordinary Linux source archive. Every
native role is checked before and after every patch, with zero fuzz and no
accepted offsets. Ordinary Linux keeps its existing configuration, patch policy,
features and output layout. The separate `linux-controller-q35-cold-source`
package verifies source application directly from the archive; it does not
depend on a previously compiled ordinary kernel or advertise compilation.

The chain retains the seven controller stages, the complete PIC/EOI/PIT source
prerequisites and original initializer, then adds the reviewed cumulative Q35
memory/configuration/MSR/routing/device, once-retained CPU/scalar, loaded-counter
and unsigned-picosecond prototype source. Existing file licenses and complete
MIT notices remain intact. New private kernel helpers are listed in the local
source license inventory. These objects do not cross the public process protocol.

Capability `0xa043` remains unavailable, and the selected native `KVM_RUN` fence
remains closed. Its prototype can reserve an original pre-vCPU clock plan and
private response journals. It preserves the actual disabled constructor clock,
retains copied control input and cached native output, uses an unsigned PS grid,
and separates ceiling stop requests from returned native RUN and pending-I/O
closure. `RUNS_CLOSED` covers that kernel cut; it does not certify pending device
timer work, QEMU worker parking or an output publication cohort. Positive active
controller source models explicitly provide a modeled future installation peer.
They do not demonstrate that the current kernel installs execution permission.

Capability `0xa044` prepares the loaded RDTSC/RDTSCP interception state for each
original worker. Capability `0xa042` remains reserved for a future CPU-output
reader. Constructor-only editions `0xa033` through `0xa041` retain their separate
contracts and confer no whole-node execution permission.

The source milestones have scoped configured translation-unit and complete-source
control evidence. A complete kernel link, original QEMU issuer/default-board join,
active interrupt/timer installation, physical quantum stop, output sealing and
source-built nested guest witness remain required. No host kernel, module,
sysctl or reboot change is part of qualification. An eventual nested guest must
retain the complete default Q35 board and provide negative controls showing
that late RUN owners, pending I/O, device work or unsealed outputs prevent the
next logical interval. Native nondeterministic execution remains explicit.
